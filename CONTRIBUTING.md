# Contributing to KCCIM

## ***Thanks for your interest in KCCIM!***

### Code style

1. C
    * Use **snake_case** for C files.
    * Publicly exported API functions must be prefixed with **kccim_**

2. C#
    * **PascalCase** for classes/methods, **_camelCase** for private fields
    * Use Allman style for brackets.

### Pull-Request

1. Free to use LLMs for contributing
2. Implement your changes, keeping commits focused and granular.
